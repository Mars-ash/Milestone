## Detail Verifikasi Acceptance Test (AT07–AT11, AT26–AT28)

1. **AT07 (Satu progress dapat memiliki banyak problem dan corrective action):**
   - Banyak problem per progress; banyak corrective action per problem card.
   - Terverifikasi di `tests/Feature/Progress/CorrectiveActionTest.php::test_at07_multiple_problems_with_multiple_actions_per_problem`.
2. **AT08 (Next Action berada pada progress, terpisah dari problem):**
   - Next Action dapat berdiri sendiri tanpa problem; actual date nullable tanpa target date.
   - Terverifikasi di `tests/Feature/Progress/NextActionTest.php::test_at08_independent_next_actions_on_progress_without_problems`.
3. **AT09 (Feedback Customer berulang dengan PIC dan tanggal mandiri):**
   - Riwayat feedback berulang; tanggal feedback berbeda dari tanggal aktivitas; PIC Feedback tidak mengambil alih PIC Customer progress.
   - Terverifikasi di `tests/Feature/Progress/FeedbackTest.php::test_at09_repeated_feedbacks_with_independent_pic_and_date`.
4. **AT10 (PIC teks bebas dan actual date nullable tanpa target date):**
   - Corrective Action dan Next Action mendukung PIC bebas; actual date boleh null; tidak ada target date atau status selesai otomatis.
   - Terverifikasi di `tests/Feature/Progress/CorrectiveActionTest.php::test_at10_action_actual_date_nullable_and_free_text_pic` dan `tests/Feature/Progress/NextActionTest.php::test_at10_next_action_actual_date_nullable_and_free_text_pic`.
5. **AT11 (Atomisitas Simpan: rollback seluruh mutasi jika terjadi kegagalan anak):**
   - Satu transaksi DB atomik: jika salah satu baris anak gagal validasi atau penyimpanan, seluruh mutasi dibatalkan, tidak ada baris setengah tersimpan, dan berkas staging tetap utuh untuk retry.
   - Terverifikasi di `tests/Feature/Progress/SaveGraphTest.php::test_at11_rollback_on_child_validation_failure_preserves_staging`.
6. **AT16 (Penolakan injeksi ID lintas progress/problem):**
   - Menolak ID corrective action, problem, next action, atau feedback yang bukan milik progress target.
   - Terverifikasi di `tests/Feature/Progress/SaveGraphTest.php::test_at16_rejects_cross_progress_corrective_action_id` dan `test_at16_rejects_cross_progress_next_action_and_feedback`.
7. **AT26 (Isolasi foto dan caption per problem):**
   - Dua problem dengan foto dan caption berbeda tetap terisolasi pada problem masing-masing setelah disimpan.
   - Terverifikasi di `tests/Feature/Progress/ProblemPhotoGalleryTest.php::test_at26_photos_and_captions_isolated_per_problem`.
8. **AT27 (Proteksi otorisasi unduh/preview & penolakan berkas palsu):**
   - Permintaan unduh/preview/thumbnail tanpa sesi dialihkan ke login; berkas non-gambar dengan ekstensi palsu ditolak oleh server; thumbnail non-destruktif menjaga byte sumber.
   - Terverifikasi di `tests/Feature/Progress/ProblemPhotoGalleryTest.php::test_at27_unauthenticated_download_and_preview_are_blocked` dan `test_rejects_fake_image_uploads`.
9. **AT28 (Enam dokumen baru dapat menjadi enam entri; metadata lama tidak memiliki unduh aktif):**
   - Enam dokumen baru berhasil diunggah tanpa batasan slot 5 kolom lama; entri metadata arsip Access ditampilkan dengan badge "File lama tidak dimigrasikan" tanpa tombol unduh atau link aktif.
   - Terverifikasi di `tests/Feature/Progress/DocumentAndLegacyMetadataTest.php::test_at28_six_new_documents_can_be_uploaded_and_persisted` dan `test_at28_legacy_metadata_only_entries_have_no_active_download`.

## Keputusan OP03 yang Ditetapkan

- **Batas Foto:** Maksimum 5 MB per file; format yang diizinkan: JPG/JPEG, PNG, WebP; verifikasi isi file riil menggunakan GD extension.
- **Batas Dokumen:** Maksimum 10 MB per file; format yang diizinkan: PDF, Excel/Office (`.xlsx`, `.xls`), Word (`.docx`, `.doc`), PowerPoint (`.pptx`, `.ppt`), Teks/Data (`.txt`, `.csv`), Arsip (`.zip`).
- **Disk Penyimpanan:** Disk privat Laravel (`private`), berkas disimpan dengan storage key acak UUID (`attachments/{uuid}`) tanpa mempercayai path atau nama asli dari request browser.
