## Detail Verifikasi Acceptance Test (AT12–AT25, AT37)

1. **AT12 (Autosave Parsial & Indikator Save State):**
   - Autosave menyimpan perubahan bertahap tanpa memaksa validasi ketat kelengkapan form.
   - Status indikator UI (*Draft tersimpan*, timestamp, peringatan konflik).
   - Terverifikasi di `tests/Feature/Drafts/SaveDraftTest.php`.
2. **AT13 (Recovery Draft saat Reload/Navigasi):**
   - Refresh browser atau berpindah halaman mengembalikan input form dan struktur anak yang belum disimpan.
   - Opsi konfirmasi buang draft membersihkan state dan mengembalikan tampilan bersih.
   - Terverifikasi di `tests/Feature/Drafts/DraftRecoveryTest.php`.
3. **AT14 & AT15 (Proteksi Konkurensi & Deteksi Konflik Dua Tab):**
   - Request out-of-order dengan sequence lebih rendah diabaikan.
   - Tab sekunder yang mengirim draft dengan `draft_revision` lama mendapat penolakan 409 Conflict.
   - Terverifikasi di `tests/Feature/Drafts/DraftConcurrencyTest.php`.
4. **AT16 & AT17 (Apply Draft Atomik & Idempotensi Replay):**
   - Penyimpanan final menerapkan graph secara atomik dalam satu transaksi.
   - Replay simpan berulang (misal double-click atau network retry) menghasilkan record yang sama persis tanpa duplikasi baris.
   - Terverifikasi di `tests/Feature/Drafts/ApplyDraftTest.php`.
5. **AT18 & AT19 (Pembuangan Draft & Staging Cleanup):**
   - Buang Draft membersihkan staging file yang tidak terpakai oleh draft/progress lain.
   - Perintah `php artisan cleanup:staging --dry-run` mendeteksi file yatim piatu tanpa menghapus sembarangan.
   - Terverifikasi di `tests/Feature/Drafts/DiscardDraftTest.php`.
6. **AT20 & AT21 (Siklus Manual Close & Reopen):**
   - Penutupan progress hanya dilakukan atas aksi eksplisit admin, menaikkan revision, menolak edit langsung pada status Closed.
   - Reopen mengembalikan status menjadi Open tanpa mengubah isi graph atau actual date.
   - Terverifikasi di `tests/Feature/Progress/CloseReopenTest.php`.
7. **AT22 (Close saat Ada Draft Belum Diterapkan):**
   - Menjelaskan bahwa Close menutup versi tersimpan di server.
   - Memberi pilihan untuk menyimpan draft terlebih dahulu atau langsung menutup versi tersimpan.
   - Terverifikasi di `tests/Feature/Progress/CloseReopenTest.php`.
8. **AT23 (Tiga Ringkasan Dashboard):**
   - Open Progress tersimpan, Draft Aktif, Aktivitas Bulan Berjalan.
   - Dihitung akurat tanpa duplikasi baris akibat join anak dan legacy date null diabaikan.
   - Terverifikasi di `tests/Feature/Dashboard/DashboardSummaryTest.php`.
9. **AT24 & AT25 (Daftar Kerja, Filter PIC Multi-Peran, Pagination & Sort):**
   - Filter PIC mencakup PIC Progress (default) dan relasi anak via query `EXISTS` tanpa duplikasi baris.
   - Filter JO, part no, part name, customer, activity, tanggal, status.
   - Pengurutan Open terlama dengan pagination 25 baris per halaman.
   - Terverifikasi di `tests/Feature/Progress/ProgressFilterTest.php`.
10. **AT37 (End-to-End Browser Workflow & Failover):**
    - Skenario operasional harian: pembuatan progress baru, autosave parsial, reload recovery, penambahan anak, upload lampiran, finalisasi simpan, manual close/reopen, monitoring dashboard, dan filter daftar kerja.
    - Terverifikasi di `tests/Feature/Progress/ProgressWorkflowTest.php` dan `tests/Browser/progress-workflow.spec.js`.

## Batasan Bisnis yang Tetap Dipatuhi

1. **Single Admin:** Sistem tetap memiliki tepat satu user admin (`admin_slot = true`); proteksi otorisasi penuh pada semua mutasi dan unduh lampiran.
2. **PIC Teks Bebas:** Tidak ada tabel master pegawai/PIC; semua PIC disimpan sebagai teks bebas.
3. **Format Angka Asli:** Field numerik raw (`qty_material_raw`, `qty_process_raw`, `qty_sample_raw`, `die_high_raw`) tetap mempertahankan string input apa adanya termasuk koma dan titik.
4. **Tanpa Penutupan Otomatis:** Status Closed hanya dicapai melalui tindakan admin eksplisit.
5. **Lampiran Privat:** Seluruh berkas tersimpan pada disk privat dan hanya dapat diakses melalui verifikasi session admin.
